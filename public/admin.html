Admin

Changes here apply to every open CafeQ app straight away. No redeploy needed.

Sign in

Admin accounts are created by the project owner in the Firebase console (Authentication → Users), then marked as admin. See the README, "Admin setup".

Not authorised

You're signed in, but this account isn't an admin, so no admin data was loaded.

To make it an admin, the project owner runs npm run make-admin -- your@email, or creates the Firestore document admins/ in the console.

Import names from a menu photo (OCR draft)

Runs text recognition (tesseract.js) in your browser; the photo is not uploaded anywhere. The result is a rough draft of item names only. Tap a line to copy it into "Add item", fix it, and enter the prep time yourself. Nothing is saved automatically.
